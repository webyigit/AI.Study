Module 4-5

스프레드시트·데이터 분석에 AI 활용

엑셀 데이터를 붙여넣고 AI에게 패턴을 찾게 하는 방법과, 데이터분석에서 AI를 쓸 때 절대 건너뛰면 안 되는 검증 습관을 다룹니다.

본문 한눈에 정리 용어 상세 참고문헌

홈닉 앱 사용 로그를 엑셀로 받으면, 행이 수천 개씩 되는 경우가 흔합니다. 피벗 테이블을 돌리기 전에 "일단 어떤 패턴이 있는지 감을 잡고 싶다"는 순간, AI에게 데이터를 붙여넣고 물어보는 것이 꽤 쓸모 있습니다. 다만 AI는 숫자를 "느낌으로" 읽는 존재이기도 해서, 계산 실수를 하는 경우가 실제로 있습니다. 이번 모듈은 이 두 얼굴을 모두 다룹니다.

1) AI에게 스프레드시트를 맡기면 잘하는 것들

작업홈닉 예시
패턴·이상치 발견"이 표에서 이상하게 이탈률이 튀는 주가 있어?"라고 물으면 후보 구간을 짚어줌
데이터 요약 및 그룹화기기 종류별 사용 시간을 붙여넣고 "카테고리별로 묶어서 요약해줘"
비전공자도 이해하는 해설"이 표가 무슨 의미인지 비전공자도 알아듣게 3줄로 설명해줘"
수식·함수 추천"이 두 시트를 매칭하려면 어떤 함수를 쓰면 좋을지"를 물어보고 수식만 받아옴
초벌 리포트 초안표 데이터를 바탕으로 주간 사용 현황 리포트 초안 텍스트 생성
프롬프트 예시
"아래는 홈닉 앱의 최근 4주 기기별 사용 횟수 표야. 전주 대비 사용량이 눈에 띄게 줄어든 기기가 있는지, 있다면 몇 주차에 얼마나 줄었는지 짚어줘. 표로 정리해줘."

2) AI는 계산기가 아니다 — 숫자를 틀리는 이유

LLM 기반 AI는 기본적으로 "다음에 올 가능성이 높은 단어"를 예측하는 방식으로 작동합니다. 표 계산 전용 엔진이 아니기 때문에, 특히 아래 상황에서 계산 실수가 발생하기 쉽습니다.

실수가 잦은 상황이유
행 수가 매우 많은 표를 통째로 붙여넣었을 때중간 행을 누락하거나 잘못 집계할 가능성이 커짐
합계·평균 등 정밀한 수치 계산패턴 예측 방식이라 실제 사칙연산 결과와 미세하게 어긋날 수 있음
표 형식이 깨져 있거나 병합 셀이 많을 때어느 값이 어느 항목에 속하는지 잘못 매칭할 위험
퍼센트·증감률 해석기준값을 착각해 증감률을 반대로 말하는 경우가 있음

IBM 등 여러 기관이 지적하듯, 생성형 AI는 "그럴듯하지만 틀린 답"을 자신 있게 내놓는 특성(할루시네이션)이 있습니다. 스프레드시트 숫자도 예외가 아닙니다.

3) 그래서 반드시 지켜야 하는 검증 습관

습관방법
핵심 숫자는 직접 재계산보고서에 들어갈 합계·평균 등 중요 수치는 엑셀 수식으로 한 번 더 검증
표 대신 요약 근거를 요구"어떤 행을 근거로 이 결론을 냈는지" 물어보고 원본과 대조
큰 표는 나눠서 분석수천 행을 한 번에 맡기지 말고, 구간을 나누거나 피벗 결과만 붙여넣기
결과를 다른 방식으로 재질문같은 데이터를 다른 각도로 다시 물어봐서 답이 일관되는지 확인
검증 프롬프트 예시
"방금 계산한 '3주차 평균 사용 횟수 42회'가 어떤 행들을 근거로 나온 숫자인지, 사용한 행 번호와 값을 나열해줘." — 이렇게 근거를 되짚게 하면, AI가 지어낸 숫자인지 실제 계산인지 바로 드러납니다.

4) 실무 워크플로 — 엑셀과 AI를 오가며 쓰기

가장 안전한 방식은 "1차 감 잡기는 AI, 최종 숫자는 엑셀"로 역할을 나누는 것입니다.

단계도구
1. 어떤 패턴이 있을지 가설 세우기AI에게 원본 데이터 요약·이상치 후보를 물어봄
2. 실제 수치 확정엑셀 피벗 테이블·수식으로 AI가 짚은 구간을 직접 재계산
3. 해설·리포트 초안 작성확정된 숫자를 다시 AI에 주고, 비전공자용 설명 문장으로 다듬기

이렇게 하면 AI의 강점(빠른 탐색, 쉬운 설명)과 엑셀의 강점(정확한 계산)을 각각 제자리에서 쓸 수 있습니다.

정리하면

구분핵심
AI가 잘하는 일패턴 탐색, 그룹 요약, 비전공자용 해설, 수식 추천
AI가 틀리기 쉬운 일대량 데이터의 정밀 합계·평균·증감률 계산
핵심 습관보고서에 쓸 숫자는 반드시 엑셀로 재계산해 검증
역할 분담가설 탐색은 AI, 최종 확정 숫자는 엑셀 수식
이해 확인 — "AI가 계산해준 숫자를 검증 없이 보고서에 바로 쓰면 안 되는 이유"를 스스로 한 문장으로 말해보세요. 다음 모듈(4-6. 업무에 AI 쓸 때 보안·저작권 체크리스트)에서는 이런 데이터를 AI에 입력할 때의 보안 문제를 다룹니다.

용어 상세

본문에서 밑줄 친 용어를 클릭하면 여기로 이동합니다. 각 항목의 "본문으로" 링크로 원래 위치로 돌아갈 수 있습니다.

엑셀 (Excel / 스프레드시트)

↑ 본문으로

행과 열로 이루어진 표 형태로 데이터를 입력·계산·정리하는 소프트웨어, 또는 그 표 형식 자체를 말합니다. 기획자가 사용 로그, 설문 결과, 매출 데이터 등을 다룰 때 가장 흔히 접하는 데이터 형태이며, AI에 데이터를 넘길 때도 표(CSV·복사 붙여넣기) 형태로 전달하는 경우가 많습니다.

데이터분석 (Data Analysis)

↑ 본문으로

수집된 데이터에서 의미 있는 패턴·추세·인사이트를 찾아내는 작업입니다. 단순 집계(합계·평균)부터 이상치 탐지, 추세 분석까지 폭넓게 포함하며, AI는 이 중 특히 "패턴을 빠르게 훑어보고 가설을 세우는" 초기 탐색 단계에서 유용합니다.

할루시네이션 (Hallucination)

↑ 본문으로

생성형 AI가 실제로는 근거가 없는 내용을 마치 사실인 것처럼 그럴듯하게 만들어내는 현상입니다. 스프레드시트 분석에서는 존재하지 않는 수치나 잘못된 계산 결과를 자신 있게 제시하는 형태로 나타날 수 있어, 결과를 그대로 신뢰하지 않고 원본과 대조하는 습관이 필요합니다.

피벗 테이블 (Pivot Table)

↑ 본문으로

많은 양의 표 데이터를 원하는 기준(예: 기기 종류별, 주차별)으로 자동으로 묶고 집계해주는 엑셀·스프레드시트 기능입니다. AI가 찾아낸 패턴 가설을 실제 숫자로 확정할 때, 피벗 테이블로 재계산해 검증하는 것이 안전한 방법입니다.
